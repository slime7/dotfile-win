# /task-done <task_id>

用于在完成功能实现与验证后，执行完整门禁、提交推送并汇报任务完成。

## 执行步骤

### 1. 验证阶段
确认本地所有门禁已全绿通过：
- 代码风格与 Lint 检查全通过。
- 单元与集成测试全量通过，且覆盖率达到项目门槛。
- 核心功能或冒烟测试通过。
- 静态分析无新增告警（符合童子军规则与零增量规则）。

### 2. 提交与推送
- 确保相关架构文档与 ADR 已按规范更新并纳入暂存区。
- 执行本地提交，并执行 `git push` 推送至远端（绝不使用 `--no-verify`）。
- 若推送被 Git Hook 拦截，阅读错误信息并修复，严禁强推或绕过。

### 3. 更新任务状态并附验收评论
在任务跟踪系统中将任务状态更新为 `In Review`，并发表标准交付汇报：
```text
✅ 任务实现完成。

**变更概要：** [简明扼要说明本次核心逻辑与变动点]
**ADR 决策：** [若有新 ADR 则引用，否则注明无]
**测试与覆盖率：** [测试执行情况与覆盖率指标]
**QA 验证：** [简述本地或端到端验证结果]
```
