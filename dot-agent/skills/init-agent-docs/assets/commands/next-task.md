# /next-task

从任务队列中按照规范认领下一个待处理任务。

## 领用步骤

### 1. 抓取待处理任务
按照优先级顺序拉取任务：
- **优先拉取 `To Rework`（待返工）状态的任务**。
- 若无待返工任务，拉取 `Open`（就绪）状态的任务。

### 2. 按优先级排序
在同一状态列表中，强制按优先级从高到低排序（如 P1 → P2 → P3 → P4）。严禁在存在高优先级任务时领用低优先级任务。

### 3. 领用并声明（防碰撞）
在着手编码前，将该任务移动至 `In Progress` 状态，并发表启动评论：
```text
🚀 开始推进此任务。[简要实现思路或修复点]
```

### 4. 获取任务上下文
读取任务描述、关联需求文档与全部历史评论（对于 To Rework 任务，重点关注审核未通过的反馈），开始进入 TDD 开发流程。
