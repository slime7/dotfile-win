# 包管理与依赖规范

当涉及项目初始化、依赖安装或包管理操作时，必须遵循以下规范：

## Node.js

- **首选工具**: 默认且优先使用 **`pnpm`**。
- **指令规范**: 使用 `pnpm add`, `pnpm install`, `pnpm run` 等标准指令。
- **环境一致性**: 确保 `pnpm-lock.yaml` 得到正确维护。

## Python

- **首选工具**: Python 环境默认且优先使用 **`uv`**。
- **指令规范**: 优先使用 `uv pip`, `uv venv`, `uv run`, `uv add` 等标准指令。
- **环境一致性**: 确保虚拟环境和锁定文件（如 `uv.lock`）得到正确维护。
